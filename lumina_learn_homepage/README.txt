LUMINA LEARN HOMEPAGE — QUICK START

Files:
- index.html: single-page homepage with sections and navigation anchors
- style.css: layout, hover dropdown, smooth scrolling, CSS-only image slider, responsive styles
- images/: put your own images here

To run:
1. Keep index.html and style.css in the same folder.
2. Add three image files:
   images/learning1.jpg
   images/learning2.jpg
   images/learning3.jpg
3. Optional: add images/zalo-icon.png for the floating Zalo button.
4. Open index.html in your browser or use Live Server in VS Code.

Important:
- This project uses HTML and CSS only; there is no JavaScript.
- The dropdown opens on hover and keyboard focus. Its links jump to sections on the same homepage.
- Smooth scrolling is controlled by `scroll-behavior: smooth`.
- The image slider uses radio inputs and CSS `:checked` selectors.
- Change the Zalo URL in index.html to the real profile/contact URL you want to use.
- Replace the example Jira and GitHub links in the footer with your team's actual links.
- The Apply button currently links to the Call to Action section. Change it to apply.html if you have a separate application page.
